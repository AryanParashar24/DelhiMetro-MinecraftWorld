# AAA Minecraft Metro Megacity: "Delhi Metro"

Welcome to the Delhi Metro Megacity project repository! This repository is dedicated to the planning, design documentation, and datapack setup for a premium, fictional AAA Minecraft Java Edition megacity inspired by Delhi, featuring an expansive metro system overseen by the Delhi Mass Rapid Transit Authority (DMTA).

## Datapack

The repository includes a Minecraft datapack in the `datapack/` directory utilizing `pack_format: 15` (Minecraft 1.20.x). It contains setup scripts, metro arrival announcement logic, and custom loot tables for the city.
