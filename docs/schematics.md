# Schematics & Tooling Strategy

To efficiently build a massive 6000x6000 city, extensive use of schematics is required.

## WorldEdit Schematics
Used primarily for copy-pasting repetitive structural elements and bulk terrain shaping:
- Standard residential towers and apartment blocks.
- Modular road segments (intersections, straightaways, BRT lanes).
- Metro tunnel rings and track segments.
- Basic platform modules for at-grade stations.

## Litematica Schematics
Used for placing complex, detailed structures where precision is key:
- Multi-directional track interchanges.
- Intricate architectural facades for modern skyscrapers.
- Custom custom-built trees (Banyan, Neem, Peepal).
- Detailed interior rooms (offices, hotel lobbies).

## Axiom Mod
Highly recommended for rapid, organic landscaping:
- Sculpting riverbanks and the Neel River.
- Smooth terrain transitions.
- Quick block palette replacements and detailing.
